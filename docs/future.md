# Future

Parked out of 1.0. Not committed work.

- **Shortcuts** — a global key combo to open the panel, and `Cmd+1`–`Cmd+9` to pick a row. All keyboard control is out of v1.
- **Auto-paste** — paste into the front app instead of only setting the clipboard. Costs Accessibility permission and the sandbox; see `docs/adr/0001`.
- **Ignored apps** — never save copies made in a named app. The concealed-copy skip already covers password managers.
- **Encrypt the saved file** — a key in the Keychain. Protects the file inside Time Machine backups.
- **Signed and notarised download** — 99 USD/year. Only needed to ship a prebuilt app without a manual approval step.
- **Bulk clip management** — select many clips and delete them together.
